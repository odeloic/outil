Outil is a simple agentic coding review tool.

# Writing Code
- Narrative comments are not allowed. The code is the only source of truth. Everything else belongs to the README, also when necessary

# Commit style
- conventional commit, one concise line message, without commit body: feat|chore|fix|perf(ui|backend|agent)

# Task tracking
- Tasks live in the Notion "Tasks" database (IDs like `REV-1`): https://app.notion.com/p/4688b28ec5d34a5cb3169897d348df83
- Parent project page "Diff Review Tool": https://app.notion.com/p/3eaba9d35e29815e9192f2444bb67f7c
- Use the `create-task` and `update-task` skills (`.claude/skills/`) to add tasks or record progress
